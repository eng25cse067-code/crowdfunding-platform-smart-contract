\# Crowdfunding Platform Using Smart Contracts



\## 1. Project Overview

The Crowdfunding Platform is a blockchain-based application that allows people to raise funds for different purposes using smart contracts.



Users can create fundraising campaigns, donate cryptocurrency, track campaign progress, and receive refunds if the funding goal is not achieved.



\## 2. Objectives

\- To develop a decentralized crowdfunding platform.

\- To allow users to create fundraising campaigns.

\- To enable secure donations using Ethereum.

\- To track the amount collected in each campaign.

\- To provide refunds when campaign goals are not reached.

\- To allow campaign creators to withdraw funds after successful fundraising.



\## 3. Technologies Used

\- \*\*Solidity:\*\* Smart contract programming language.

\- \*\*Ethereum:\*\* Blockchain platform.

\- \*\*Remix IDE:\*\* Writing, compiling, and deploying smart contracts.

\- \*\*JavaScript:\*\* Supporting blockchain development.

\- \*\*GitHub:\*\* Source code management.



\## 4. Main Features

1\. \*\*Create Campaign:\*\* Users can create campaigns with a title, description, funding goal, and deadline.

2\. \*\*Donate Funds:\*\* Users can contribute ETH to campaigns.

3\. \*\*Track Progress:\*\* View the total amount collected and funding progress.

4\. \*\*View Backers:\*\* Check the wallet addresses of people who donated.

5\. \*\*Withdraw Funds:\*\* Campaign creators can withdraw funds when the goal is achieved and the deadline has passed.

6\. \*\*Refund Donations:\*\* Donors can claim refunds if the campaign fails to reach its funding goal.



\## 5. Project Workflow

1\. Deploy the smart contract using Remix IDE.

2\. Create a fundraising campaign.

3\. Allow users to donate ETH.

4\. Track donations and campaign progress.

5\. Check whether the funding goal is achieved.

6\. Withdraw funds or process refunds based on the campaign result.



\## 6. How to Run the Project



\### Step 1: Open Remix IDE

Visit https://remix.ethereum.org/



\### Step 2: Create a Solidity File

Create a file named `Crowdfunding.sol`.



\### Step 3: Add Smart Contract Code

Copy the crowdfunding smart contract code into the file.



\### Step 4: Compile

Select Solidity compiler version `0.8.20` or a compatible version and compile the contract.



\### Step 5: Deploy

Open Deploy \& Run Transactions, select Remix VM, and deploy the contract.



\### Step 6: Test

\- Create a campaign.

\- Donate ETH from another account.

\- Check campaign progress.

\- Test withdrawal and refund features.



\## 7. Expected Outcome

The project provides a simple decentralized crowdfunding system where users can create campaigns, donate funds, monitor fundraising progress, and receive refunds when funding goals are not achieved.

\## 9. Conclusion

This project demonstrates how blockchain technology and Solidity smart contracts can be used to create a transparent and decentralized crowdfunding platform. It reduces the need for intermediaries and provides automated donation, withdrawal, and refund operations.
